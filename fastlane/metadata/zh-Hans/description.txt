AI Token Watch 是一款原生 macOS 菜单栏应用，帮助你从本机 coding agent 记录中了解 token 用量和预估费用。它支持读取 Claude Code、Codex 、OpenCode、Antigravity 的本地使用数据，并把分散的会话记录整理成清晰的每日、每月、模型、项目和来源统计。

你可以在菜单栏快速查看今日、本周、本月的 token 消耗，也可以打开窗口查看最近 30 天、最近 12 个月趋势、模型消耗排行、来源占比、项目使用情况和最近会话明细。日历热力图和图表适合快速发现高消耗日期、使用节奏和成本变化。

TokenWatch 只在你的 Mac 上工作。应用会在你授权后读取本地文件，并在本机完成解析、汇总和费用估算。它不需要账户，不包含广告、分析、遥测或追踪，也不会上传你的使用记录、项目路径、prompt、response 或价格数据。

费用为基于内置价格数据的估算值，可能与上游服务的正式账单不同。TokenWatch 更适合作为日常观察、复盘和成本感知工具，而不是财务结算依据。
